Discord Message Cleaner

Deletes your own messages. Runs entirely in your browser; your token only goes to discord.com. Not affiliated with Discord. Automating a user account is against Discord's Terms and may get it limited or banned. Deleted messages can't be recovered.
Token: discord.com/app → F12 → Network → filter api → click a request → Request Headers → authorization. Never share it.
